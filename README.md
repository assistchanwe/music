# 🎤 내 음역대 찾기

마이크로 음역대(최저음~최고음)를 측정하고, 내 목소리에 맞는 노래를 추천해주는 웹앱.

## 기능

- **가이드 측정 (정밀)**: 기준음을 들려주면 따라 부르는 방식. 반음씩 내려가며 최저음을,
  올라가며 최고음을 찾는다. (연속 2회 실패 시 한계로 확정)
- **자유 발성 측정 (빠름)**: 자유롭게 소리를 내면 실시간 피치 미터로 표시하고,
  0.3초 이상 유지된 최저/최고음을 기록.
- **결과**: 피아노 건반 시각화, 한국식 옥타브 표기(예: 2옥타브 라), 예상 성종
  (베이스~소프라노), 음역 폭.
- **노래 추천**: 내장 곡 DB(K-pop/가요/팝송 약 105곡)와 매칭해
  *편한 곡 / 원키 도전 곡 / 키 조절(±n키) 필요 곡*으로 분류. 장르 필터 지원.
- 측정 이력은 localStorage에만 저장 — 마이크 데이터는 브라우저 밖으로 전송되지 않음.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트 (Vitest)
npm run build    # 프로덕션 빌드
```

> 마이크 권한이 필요하므로 `localhost` 또는 HTTPS에서만 동작한다.
> 가이드 측정 시 이어폰을 사용하면 기준음이 마이크에 섞이지 않아 더 정확하다.

## 구조

| 경로 | 역할 |
|---|---|
| `src/audio/pitchDetector.ts` | McLeod Pitch Method(NSDF) 기반 f0 추출 |
| `src/audio/notes.ts` | Hz ↔ MIDI ↔ 음이름/한국식 옥타브 표기 변환 |
| `src/audio/mic.ts` | getUserMedia + AnalyserNode 래퍼, 기준음 재생 |
| `src/test-modes/` | 가이드/자유 발성 측정 UI |
| `src/result/voiceType.ts` | 음역대 → 성종 분류 |
| `src/recommend/recommend.ts` | 음역대 매칭·키 조절량 계산 |
| `src/recommend/songs.json` | 곡 DB (음이름 문자열로 저장) |

## 참고

- 곡별 음역대 데이터는 공개된 노래방 음역 자료 기준의 **근사치**이며, 라이브/음원 버전에
  따라 다를 수 있다.
- 피치 감지 정확도는 합성 사인파 기준 ±5센트 이내 (단위 테스트로 검증).
